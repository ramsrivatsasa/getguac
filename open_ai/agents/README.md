# open_ai Agents

This folder contains the durable agent profiles used for GetGuac work.

## Available agent profiles

- `getguac-design-agent.md` — GetGuac UI, content, asset-selection, and verification rules.

The repository-root `AGENTS.md` remains the automatic entry point for Codex and other compatible coding agents. It directs agents to the detailed files stored here and in `web/docs`.
