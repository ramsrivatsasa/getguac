## P0 bugs the code review caught + fixed

1. **smashDays UTC/local drift.** Web used UTC midnight, mobile used local midnight. Same user → different streak count between web + mobile on day boundaries. Both now use local-Date parts. ([web/src/lib/smashDays.js](web/src/lib/smashDays.js))
2. **Referral feature was dead on the dashboard.** `apply_referral_code` wrote `profiles.smash_days_bonus`, but neither dashboard fetched the column or passed it to `computeSmashDays`. Now both web (TanStack query) and mobile (initState fetch + setState) load + pass it. The whole referral system was decorative before this fix.
3. **Cron auth bypass.** `/api/cron/usage-snapshot` trusted the client-settable `x-vercel-cron` header. Switched to `CRON_SECRET` Bearer pattern matching other crons. ([web/src/app/api/cron/usage-snapshot/route.js](web/src/app/api/cron/usage-snapshot/route.js))
