Item Card — Cross-Platform Contract

Single canonical spec at test-fixtures/item-card-scenarios.json. Mobile renders via FetchCard (Flutter). Web renders via ItemRowCard (React). Both must produce visually-equivalent output for the same props.

Prop contract

PropTypeDefaultDescription
titlestring—Item name. Truncates to 2 lines.
subtitlestring?—One-sentence metadata line (≤ 2 lines).
imageEmojistring?—Emoji rendered in the tinted image tile when no URL.
imageUrlstring?—Product image URL. Falls back to imageEmoji on error.
tintcolor hex—Tile-bg color. Card body is always white.
urgencystring?—Top-of-content pill. Lightning bolt added when text contains 'left'.
urgencyBgcolor hex?—Urgency pill background. Defaults to rose-200.
urgencyFgcolor hex?—Urgency pill text/icon. Defaults to rose-900.
storeNamestring?—Pill in the utility row — store name, on-hand, etc.
storeColorcolor hex?—Color for the store-emoji circle in the pill.
storeEmojistring?—Emoji or letter inside the store-pill circle.
valuenumber?—Right-aligned coin chip value. Formats >=1000 as 'k'.
valueLabelstringOptional currency/units string ('$', 'pts').
valueIsPrefixbooleanfalseWhen true, label goes BEFORE the number ('$ 42').
ratingint 0..50Star count to display in the utility row.
savedbooleanfalseHeart filled (pink) when true.
onTapcallback?—Tap-the-card target.
onRatecallback?—Per-star tap. When null, the star row is hidden.
onToggleSavecallback?—Heart-icon tap. When null, no heart shown.
onSharecallback?—Share-icon tap. When null, hidden.
onMenucallback?—⋮-icon tap. When null, hidden.
