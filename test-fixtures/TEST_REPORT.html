What this report verifies

Both engines — web/src/lib/wizardScore.js + web/src/lib/financeInsights.js on the JS side, and mobile/lib/services/wizard_score.dart on the Dart side — run the SAME input fixture and produce identical output. If they drift, the dashboard tile and the /guacanomics / /guacwizard pages would disagree for the same user. The fixture file at test-fixtures/score-engines.json is the contract.

LayerSymptomRoot causeFix
JS financeInsights.inRange() Row dated == endStr was INCLUDED on web but EXCLUDED on Dart JS only checked since (single Date). No upper-bound support. Extended inRange to accept { start, end } object with exclusive upper bound. getPeriodStart passes through the new shape.
